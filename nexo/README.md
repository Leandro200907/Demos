# Demo NEXO para GitHub Pages

Esta carpeta contiene únicamente la demo estática. No requiere Python, base de datos ni servidor de aplicación.

## Publicar

1. Subir todo el contenido de esta carpeta a la raíz de un repositorio de GitHub.
2. En el repositorio, abrir **Settings → Pages**.
3. En **Build and deployment**, elegir **Deploy from a branch**.
4. Seleccionar la rama `main`, carpeta `/ (root)` y guardar.

GitHub mostrará la dirección pública cuando termine la publicación.

## Archivos

- `index.html`: demo guiada.
- `data.js`: datos locales de demostración.
- `assets/`: imágenes anonimizadas y PDF de ejemplo.
